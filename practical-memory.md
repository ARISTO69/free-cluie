Guide me step-by-step on Creating a Document using Paper and & Document Formatting inside MS word

Assistant:
Problem:
Create a handwritten document on paper first, then format it digitally in Microsoft Word.

Steps:

Step 1: Plan the Document on Paper
A) Take a blank A4 sheet
B) Write the title at the top center in bold letters
C) Leave a 1-inch margin on all sides
D) Write the content in short paragraphs
E) Number the pages at the bottom center

Step 2: Open Microsoft Word
A) Press Windows key to open Start menu
B) Type "Word" and press Enter
C) Click Blank Document

Step 3: Set Page Layout
A) Open the Layout tab
B) Click Size > A4
C) Click Margins > Normal

Step 4: Type the Title
A) Type the same title from your paper
B) Press Ctrl + E to center align
C) Press Ctrl + B to make text bold
D) Press Enter twice to leave space

Step 5: Type the Content
A) Type the first paragraph from your paper
B) Press Enter to start a new paragraph
C) Repeat for all paragraphs

Step 6: Format the Text
A) Select all text with Ctrl + A
B) Open the Home tab
C) Set font to Times New Roman, size 12
D) Click the Line and Paragraph Spacing button > 1.5

Step 7: Add Page Numbers
A) Open the Insert tab
B) Click Page Number > Bottom of Page
C) Select Plain Number 2

Final Result:
A properly formatted Word document matching your handwritten paper, ready for printing or submission.
